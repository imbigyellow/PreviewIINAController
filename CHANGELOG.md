# Changelog

## 1.1.0 — 2026-09-20

- Native settings window: reopen the running app to configure controls.
- Record three distinct bare letter/number keys.
- Separate backward/forward seek durations (1–3600 seconds).
- Save locally, restore defaults, reject duplicate keys and invalid durations.
- Default Q/W/E + 5s behavior and modifier pass-through preserved.
- No new polling, timers, third-party libraries or runtime shell dependencies.

## 1.0.0 — 2026-09-16

- Initial Apple Silicon release: Preview Q/W/E controls for IINA.
